    | 작업 | 입력 토큰 | 출력 토큰 |

    | 간단한 질문 답변 | 1,000 | 700 |

    | 문서 초안 작성 | 3,000 | 5,000 |

    연속 대화 5턴은 누적 대화 맥락을 포함한 합계, 에이전트 실행·제작은 해당 작업의 모델 호출 전체 합계를 가정했어요.

??? example "이렇게 읽으면 돼요"

    **GPT-6.1 Sol**로 문서 초안을 1회 쓰면 약 **50.4크레딧**이 들고, 10,000크레딧으로 약 **198회** 쓸 수 있어요.

    **Solar Pro 4**로 같은 분량을 쓰면 1회 약 **3.28크레딧**, 10,000크레딧으로 약 **3,052회**예요. 분량을 같게 가정한 것이지, 결과 품질이 같다는 뜻은 아니에요.

> 슬라이드 예시는 텍스트 원고 비용만 포함해요. 이미지·영상 생성, 검색, OCR, 파일 처리 등은 별도예요. 질문·첨부 자료·대화 이력이 길어지거나 재생성을 반복하면 사용 가능 횟수는 줄어들어요.
