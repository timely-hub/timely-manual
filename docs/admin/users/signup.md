# 가입 제한 설정

**[유저 관리] > 초대·가입 관리 > [가입 제한 설정]**에서 어드민이 정한 조건에 맞는 사람만 가입하도록 설정해요. **이메일 주소 제한**과 **약관 동의 관리** 두 가지 탭이 있어요.

## 1. 이메일 주소 제한 { #email }

가입할 수 있는 이메일 주소를 제한해요. 아무것도 등록하지 않으면 **모든 이메일 주소로 가입할 수 있어요.**

![가입 제한 설정 — 이메일 주소 제한 탭과 [+ 등록하기]](../../assets/images/admin-invite-users/v3-signup-email.png)

**[+ 등록하기]**를 누르고 허용할 주소의 **‘@’ 뒷부분(도메인)만** 입력해요.

> 💡 예를 들어 `timely.ac.kr`을 등록하면, 메일 주소가 `@timely.ac.kr`로 끝나는 사람만 이 스페이스에 가입할 수 있어요.

## 2. 약관 동의 관리 { #terms }

스페이스만의 이용 약관을 직접 등록해요. **[약관 동의 관리]** 탭에서 **[+ 등록하기]**를 누르고 제목과 내용을 작성해요.

- 등록한 약관은 **회원가입 시 유저에게 표시**되고, 유저가 동의해야 서비스를 이용할 수 있어요.
- 새로 등록한 약관은 **기존 유저가 다음에 로그인할 때** 동의 절차가 진행돼요.
