# 운영 로그

**[어드민 설정] > [운영 로그]**에서 스페이스 운영 기록을 확인해요. **감사 로그**와 **대화 이력 조회** 두 가지 메뉴가 있어요.

## 감사 로그

스페이스에서 **누가, 언제, 어떤 작업을 했는지** 기록으로 확인할 수 있어요. 개인정보 열람 기록도 여기에 남아요.

**기록에서 볼 수 있는 내용**

| 항목 | 설명 |
|---|---|
| 일시 | 작업이 일어난 날짜와 시간 |
| 카테고리 | 작업 종류 (보안 관리, 개인정보 열람 등) |
| 작업 | 실제로 한 일 (로그인, 대화 원문 열람 등) |
| 작업자 이메일 | 작업한 사람의 이메일 |
| 작업자 역할 | 스페이스 소유자 · 스페이스 관리자 · 스페이스 사용자 |
| 상세 | 작업 대상과 열람 사유 |
| 결과 | 성공 여부 |

**찾아보기**

- **월**을 골라 해당 기간의 기록을 볼 수 있어요.
- **카테고리 · 작업 · 결과**로 걸러 볼 수 있어요.
- 작업자 **이메일**로 검색할 수 있어요.
- 오른쪽 위 **[엑셀 다운로드]**로 기록을 파일로 받을 수 있어요.

## 대화 이력 조회

구성원의 **AI 대화 원문과 올린 자료**를 볼 수 있어요.

!!! warning "대화 열람 권한을 받은 관리자만 볼 수 있어요"
    권한은 **[유저 관리] > [유저 설정]**에서 줘요.

**목록에서 찾기**

- 기간, 키워드, 이메일 또는 이름으로 찾을 수 있어요.
- 많이 나온 키워드가 **TOP 1 · 2 · 3**으로 표시돼요.
- 목록에서 이메일, 이름, 유저 그룹, 키워드, 채팅명, 생성일을 볼 수 있어요.
- 오른쪽 위 **[엑셀 다운로드]**로 목록을 파일로 받을 수 있어요.

**대화 원문 열람하기**

1. 목록에서 볼 대화를 눌러요.
2. **열람 사유**를 입력해요. 대상과 채팅명을 확인한 뒤 사유를 적어야 열 수 있어요.
3. 대화 원문과 구성원이 올린 첨부 자료가 화면 오른쪽에 열려요.

> 💡 **열람한 사람·시간·사유는 기록으로 남아요.** [감사 로그](#_2)의 '개인정보 열람' 카테고리에서 확인할 수 있어요.
